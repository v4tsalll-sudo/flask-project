#  Minimal Expense Tracker

A simple and lightweight expense tracking web application built with **Flask (Python)** and **JSON** for local data persistence.

---

##  Features

- **Add Expenses:** Log expenses with a title, amount, and category.
- **Edit & Update:** Easily modify existing expense details via an interactive modal.
- **Delete Expenses:** Remove expenses in one click.
- **Summary Banner:** View the total amount spent and count of recorded expenses at a glance.
- **Automatic Timestamps:** Automatically records the date and time of each entry.
- **Persistent Storage:** Saves all data locally in `expenses.json`.
- **Modern Dark UI:** Clean, responsive, and easy-to-use interface.

---

##  Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML5, CSS3, JavaScript
- **Storage:** JSON (`expenses.json`)
